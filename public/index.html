TourTaste

Tell the agent which act is going on the road. It asks Qloo where that act's audience taste is strongest, which acts and brands the same audience likes, and writes a routing recommendation you can check against the evidence.

Describe the tour only. Please do not enter personal information about yourself or anyone else.

Taste data from the Qloo API. Affinity describes aggregate audience taste; it is not a forecast of ticket sales. Built for the Qloo Agentic Hackathon. Source
